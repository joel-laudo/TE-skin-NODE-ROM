# Area-Growth Error Tolerance Derivation (SI Figure 1)

Geometric motivation (Steiner's formula) for the area-growth error tolerance
`T(A) = max(A_min, l0*sqrt(A))` with `A_min = 5 cm^2`, `l0 = 1 cm`, used
throughout the manuscript and SI to define the acceptable-error band for
predicted final area gain (SI Section 1).

This figure was manually illustrated (not produced by a Python script or
notebook) — no generating code exists anywhere in the project. The final
output files are included here for completeness:
- `Supp_Fig_Steiner_rev.pdf`
- `Supp_Fig_Steiner_Area_rev.svg`
